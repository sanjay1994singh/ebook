# Standalone Kruti Dev conversion tool

Source: https://github.com/ltrc/kru2uni (master, retrieved 2026-09-07).
Authors: Nehal J Wani and Raveesh Motlani; Copyright 2015, Language Technology
Research Center, IIIT Hyderabad. Licensed under GPL-3.0; full license is included.

Local changes: Python 3 text/regex/UTF-8 standard-stream compatibility, generic
half-ya mapping (`î` to `्य`, verified on the pilot), and retention
of terminal halants. The complete modified source is supplied here. This is an
optional standalone command invoked through stdin/stdout, not imported by Django.
Retain the source and license when distributing this tool; account for its GPL
terms in your distribution policy.

The conversion is a draft, not verified transcription. Only use on positively
identified Kruti Dev font runs. Original source text and OCR alternatives are kept
for reviewer comparison; do not apply it indiscriminately to English/Unicode.
